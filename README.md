#  Counter App

A simple **Counter Application** built with **HTML**, **CSS**, and **JavaScript**.  
This project is part of my early JavaScript learning journey and demonstrates basic DOM manipulation and event handling.

---

##  Features
- ➕ Increase button to increment the counter  
- ➖ Decrease button to decrement the counter (cannot go below 0)  
- 🔄 Reset button to reset the counter to zero  
   Simple, clean, and responsive design using CSS  

---

## 🛠️ Technologies Used
- **HTML5** for structure  
- **CSS3** for styling  
- **JavaScript (Vanilla JS)** for functionality  

---

## 🧩 How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/MaedehSKh80/My-Counter  
2. Open the index.html file in your browser.

3. Click the buttons to increase, decrease, or reset the counter.

Updating content dynamically with JS

Preventing invalid states (like negative numbers)
